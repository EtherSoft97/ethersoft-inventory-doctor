# Inventory Doctor

Free inventory diagnostic scanner for Odoo 18.

Detect stock, valuation, costing, and configuration issues before they hit accounting.

## Features

- Inventory Health Dashboard
- 14 diagnostic checks on live database data
- Health Score with severity overview
- Top Diagnoses summary
- Scan history

## Installation

1. Copy `ethersoft_inventory_doctor` into your Odoo addons path.
2. Update the Apps list.
3. Install **Inventory Doctor**.

## Dependencies

- `mail`
- `stock_account`
- `purchase_stock`
